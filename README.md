# Universe Database

## Project Overview

This project is a relational database developed
using PostgreSQL to organize information about
celestial bodies in the universe.

It stores information about galaxies and other
astronomical objects using relational database
structures.

## Technologies Used

- PostgreSQL
- SQL

## Key Features

- Created tables for astronomical data.
- Organized galaxy types and celestial body records.
- Used Primary Keys and Foreign Keys.
- Established relationships between database tables.
- Stored information about galaxies and celestial objects.

## What I Learned

- Relational database design
- SQL table creation and modification
- Primary and Foreign Key constraints
- Database normalization
- Managing related data using PostgreSQL
